## 🧭 Choose Your Model

OpenAI's GPT Image 2.5 family includes **GPT Image 2.5 Sunburst** and **GPT Image 2.5 Flare**. Both accept text and images and produce still images. The recommendations below are separate from the provenance of the example assets.

| Comparison | GPT Image 2.5 Sunburst | GPT Image 2.5 Flare |
|---|---|---|
| Main strength | Image generation and precise editing | Fast, high-quality everyday generation |
| Choose when | Editing precision is your priority | Generation speed is your priority |
| Input | Text and images | Text and images |
| Output | Still images | Still images |
| API model ID | `gpt-image-2.5-sunburst` | `gpt-image-2.5-flare` |
| Official reference | [OpenAI documentation](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst) | [OpenAI documentation](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare) |

## 💡 10 Creative Cases

Ten workflows are planned; **six are defined so far**. C01–C02 include assembled GIFs. C03–C05 include still assets and video prompts, with video outputs pending. C06 includes a supplied video and its image-to-video prompt. C07–C10 will be introduced as their concepts are developed.

| # | Idea | Starting material | Output path |
|---|---|---|---|
| 01 | [Pixel Art Character GIF](cases/01-pixel-art-gif.md) | Text; optional character reference | Text → sprite sheet → GIF |
| 02 | [Clay Stop-Motion: Fishing for a Star](cases/02-clay-stop-motion.md) | Text | Text → frame sheet → GIF |
| 03 | [Two Characters, One Scene](cases/03-two-character-video.md) | Two character references | Images → shared keyframe → video |
| 04 | [Character to Storyboard to Film](cases/04-storyboard-video.md) | Character concept and story | Character → storyboard → video |
| 05 | [Distant Observer: A Robot in the Rain](cases/05-distant-observer.md) | Character concept and scene | Character → distant scene → video |
| 06 | [Frosted Glass Poster to 360° Orbit](cases/06-360-orbit.md) | Text or supplied poster | Text → poster → 360° orbit video |

These workflows use still-image generation followed by a separate GIF assembly or video-generation step. GPT Image 2.5 itself outputs still images.
