# Prompting Tips & Review Checklist

Start with one clear result, then describe the constraints that make it useful.

## Build a Prompt

Use this order as a writing aid: **task → subject → composition → material and style → lighting → exact copy → constraints**. Remove any part that does not apply.

For example: “Edit this product photo. Preserve the complete product and label. Place it on the right of a warm ivory scene, leaving the left side empty for copy. Use soft window light. Add no new text or props.” See [P04](../cases/p04-product-campaign.md) for the complete prompt.

## Use References Deliberately

Name the role of each uploaded image and preserve the upload order. Two identity portraits are not the same input as one opening frame containing both characters. In [C03](../cases/03-two-character-video.md), the portraits establish identities; the greenhouse image establishes the starting composition.

For a character series, reuse the original approved reference rather than using each new generation as the next reference. Compare the face, outfit, proportions, and signature details after every generation.

## Edit Locally

Describe the one element to change and what must remain fixed. In [C05](../cases/05-distant-observer.md), the flowerpot is moved outside the umbrella while retaining the robot, street, and camera. Keep the draft, correction prompt, and approved image so the revision can be understood later.

## Check Text and Structure

Quote exact copy and state where each line belongs. Inspect spelling at the final display size. Check repeated elements individually: four stickers, three accessories, two distinct people, one mug handle. A convincing overall image may still contain a wrong count or an altered label.

## Prepare Motion from an Approved Still

Write motion around the actual starting pose and visible object positions. Keep each action achievable within the chosen duration. Set the camera behavior, subject action, environmental motion, and end state separately.

For sprite GIFs, crop excess whitespace without changing the character's scale. For stop-motion sets, keep a shared crop so the scene does not jump when the subject moves. Assembly cannot supply missing poses.

For image-to-video, upload individual shot frames instead of a storyboard grid. Verify continuity of hands, grips, props, camera scale, and lighting. Matching first and last frames does not prove a complete camera orbit; [C06](../cases/06-360-orbit.md) requires reviewing the side and rear views too.

## Record What Was Actually Used

Record the generation tool, exact model ID when exposed, aspect ratio, resolution, duration, and any edits or assembly steps. Use “not recorded” or “not exposed” for missing values. Keep suggested settings separate from actual settings; publish limitations alongside the example.
