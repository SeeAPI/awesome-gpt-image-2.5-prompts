## 验收

- 摄影机实际经过侧面、背面、另一侧再返回；不能只转半圈或让杯子原地转动。
- 一只杯子、一个杯柄，杯口保持中空，材质与轮廓不变形。
- 摄影机距离、高度、焦距固定；首尾构图一致。
- SeeAPI 与 IMAGES, VIDEOS AND MODELS API 的字形、拼写和屏幕位置稳定，仅被磨砂玻璃覆盖的位置柔化。
- 不要求隐藏背面与未知真实产品完全一致；需要检查生成的背面结构是否合理。

文字若无法稳定保持，可后期合成固定字层；透过杯身的模糊与折射还需要对应遮罩处理，普通字幕覆盖不能自动还原。
