## Collected Prompts

Collected prompts retain their source text and language. Place the named prompt author, source platform, and clickable source link in a `<sub>` footer after the final full-prompt block of each case. Keep credits out of case titles and directory links.

作者、来源平台和来源链接统一放在每条案例最后一段完整提示词之后的 `<sub>` 小字中，不放在标题或目录链接旁。 A collection-page publisher is not automatically the original author. When authorship is unconfirmed, retain that status in catalog metadata and omit the placeholder author credit from public README and case pages. Keep known source links; use **Original source unconfirmed** when the original source is unknown. Never substitute SeeAPI for an unknown author.

作者未确认时，在 catalog 元数据中保留该状态，公开 README 和案例页不展示占位署名；保留已有来源链接，不将未知作者替换为 SeeAPI。

Keep Prompt authorship, adaptation credit, collection-page publisher, image provenance, and model evidence distinct. A source model label is a source claim unless independently verified. Internal review links and reviewer information are not public attribution. Follow the [Feishu update SOP](feishu-update-sop.zh-CN.md) for importing, review, and publication.
